# Power BI Dashboards

Sales and profitability dashboard built in Power BI, with a margin and pricing scenario page.

## Pages
- Executive Summary: revenue, orders, profit and returns against monthly targets
- Margin & Pricing: price, cost and volume sliders showing the effect on profit and margin against a 40% target
- Product Performance: revenue, profit and order targets by product
- Customer Insights: customer trends, segments and top customers
- Regional Sales Map: sales by region and country

## Built with
- DAX measures for targets, rolling periods and time intelligence
- What-if parameters for scenario modelling
- Custom theme, bookmarks and page navigation
- Row-level security by region

Data: Microsoft AdventureWorks sample data.
